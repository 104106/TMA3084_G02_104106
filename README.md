# TMA3084 SELab - Lab 1: Pizza Order Calculator

A Dart command-line application that calculates pizza order totals using `switch` statements and `while` loops.

## Features
- Interactive terminal input using `dart:io`.
- Supports Small ($5), Medium ($7), and Large ($10) sizes.
- Continuous ordering loop with input validation.

## How to Run
```bash
dart run pizza_order.dart
